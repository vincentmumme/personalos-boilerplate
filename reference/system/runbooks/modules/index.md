# Installierte Module

## Purpose

Diese Datei zeigt Agenten und Menschen, welche optionalen Teile in dieser PersonalOS-Instanz tatsächlich vorhanden sind.

## Ownership and Boundaries

Der Index besitzt nur die Navigation auf installierte Module. Die fachliche Wahrheit bleibt beim jeweiligen Domain- oder Systemowner. Ein installiertes Modul stellt Regeln, Beispiele oder einen zusätzlichen Bereich bereit; externe Dienste, Automationen, Agenten oder Hosts werden dadurch nicht automatisch aktiviert.
