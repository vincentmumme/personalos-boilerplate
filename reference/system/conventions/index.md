# System Conventions

## Purpose

Navigation zu systemweiten konsistenten Defaults mit einer ausdrücklich definierten Ausnahmegrenze.

## Ownership and Boundaries

Conventions legen den Normalfall fest, ohne jede begründete Ausnahme zu verbieten. Bindende Pflichten gehören nach `system/rules/`; zusammengesetzte Verträge nach `system/contracts/`.
