# Truth Systems

## Purpose

Navigation zu Authority-, Scope- und Pointer-Verträgen der beteiligten Wahrheitssysteme.

## Ownership and Boundaries

Truth-System-Records erklären, welches System welche Wahrheit besitzt und wie das PersonalOS darauf verweist. Sie kopieren keine externe Wahrheit.
