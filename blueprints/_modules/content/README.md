# Modul: Content

Optionaler Bereich für Content-Strategie, Stücke, Versionen und Veröffentlichungen.

## So nutze ich es

Ich behandle eine Idee, ein ausgearbeitetes Content Piece und eine Veröffentlichung als unterschiedliche Zustände. So bleibt sichtbar, was geplant, produziert, veröffentlicht oder bewusst verworfen wurde.

## So kannst du es ausprobieren

Nutze das Modul, wenn Content ein wiederkehrender Arbeitsbereich ist. Starte mit einem einzigen Piece und dokumentiere erst danach weitere Kanäle oder Automationen.
