# Modul: Backup und Git

Versionierung schützt Text und Systemlogik, ersetzt aber keine vollständige Backup-Strategie.

## So nutze ich es

Git macht Änderungen nachvollziehbar und synchronisiert sichere Textdateien. Pro PersonalOS-Repository übernimmt genau ein automatischer Git-Writer Commit und Push. Sensible Binärdaten, Secrets und große Datensätze erhalten getrennte Speicher- und Sicherungswege.

## So kannst du es ausprobieren

Initialisiere Git in einer Testkopie, prüfe die Ignore-Regeln und stelle eine frühere Version wieder her. Erst danach verbindest du ein privates Remote.

## Grenzen

Kein Remote, Token, Account oder automatischer Push wird eingerichtet.
