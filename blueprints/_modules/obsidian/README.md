# Modul: Obsidian

Obsidian ist eine mögliche Oberfläche für das PersonalOS, nicht dessen Fundament.

## So nutze ich es

Ich öffne denselben lokalen Ordner als Vault. Wikilinks, Suche und Graph helfen bei Navigation und Verständnis; die Markdown-Dateien bleiben die Wahrheit.

## So kannst du es ausprobieren

Öffne eine Kopie deines PersonalOS in Obsidian. Installiere zunächst keine Plugins und prüfe, ob Navigation und Links bereits ohne zusätzliche Komplexität funktionieren.

## Grenzen

Keine private Plugin-Konfiguration wird mitgeliefert. Das Modul verändert den Kern nicht und ist standardmäßig deaktiviert.
