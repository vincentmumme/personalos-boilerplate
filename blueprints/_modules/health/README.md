# Modul: Gesundheit

Optionaler Bereich für Gesundheitsprofil, Messwerte, Einschätzungen, Training, Pläne und Reviews.

## So nutze ich es

Ich trenne Rohdaten, persönliche Einschätzungen und daraus abgeleitete Entscheidungen. Herkunft und Zeitpunkt bleiben sichtbar, damit KI keine Momentaufnahme als dauerhafte Wahrheit behandelt.

## So kannst du es ausprobieren

Beginne mit einem kleinen, klaren Anwendungsfall. Das Modul ist Kontextverwaltung und keine medizinische Diagnose oder Behandlung.
