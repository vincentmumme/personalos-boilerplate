# Modul: Claude Code

Claude Code kann denselben PersonalOS-Ordner und dieselbe Systemlogik verwenden wie Codex.

## So nutze ich es

Werkzeugspezifische Hinweise bleiben Adapter. Sie dürfen Regeln aus dem PersonalOS nicht duplizieren oder überschreiben.

## So kannst du es ausprobieren

Lass Claude Code den Root-Einstieg lesen und eine geplante Änderung zunächst erklären. Vergleiche das Ergebnis mit dem kanonischen Owner, bevor du Schreiben erlaubst.

## Grenzen

Keine private Claude-Konfiguration, Hooks oder Berechtigungen werden übernommen.
