# Attention Triggers

## Purpose

Kanonischer Bereich für eine spätere Neubewertung, wenn heute noch kein bestätigtes Commitment besteht.

## Ownership and Boundaries

Ein Attention Trigger ist keine Action und kein Reminder auf Verdacht. Er materialisiert nur einen begründeten zukünftigen Prüfpunkt.

## Navigation

Fällige Trigger werden aus ihren atomaren Records abgeleitet und kontextbezogen neu bewertet.

## Maintenance

Nach der Prüfung wird ein Trigger aufgelöst, ersetzt oder in eine echte Action überführt.
