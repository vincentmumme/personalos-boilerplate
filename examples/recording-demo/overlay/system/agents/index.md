# Agents

## Purpose

Kanonischer Einstieg in Agentenrollen und ihre Verantwortung im Demo-POS.

## Ownership and Boundaries

Agent Records beschreiben Rolle und Scope. Das PersonalOS besitzt die gemeinsame Systemwahrheit; Tools und Runtimes sind keine zweite Wahrheit.

## Navigation

- [[system/agents/codex]] – interaktive Arbeitsoberfläche
- [[system/agents/hermes]] – dauerhaft verfügbare Runtime

## Shared Truth

Beide Agenten lesen dieselbe Kontextbasis. Das PersonalOS ist die gemeinsame Wahrheit; der Agent ist die jeweils verwendete Arbeitsoberfläche oder Runtime.

## Maintenance

Neue Agenten benötigen eine klare Rolle und Grenzen. Ein installiertes Tool erzeugt nicht automatisch eine neue Agentenidentität.
