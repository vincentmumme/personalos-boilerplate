# Kontext vor Automation

## Current Knowledge

Automationen verstärken die Struktur, auf der sie laufen. Ist der Kontext unklar, werden unklare Entscheidungen schneller und häufiger reproduziert. Deshalb stehen zuerst verständliche Owner, Regeln und wiederholbare manuelle Abläufe. Automation folgt erst, wenn diese Grundlage funktioniert.

## Applicability Boundaries

Das Prinzip gilt besonders für wachsende, kontextabhängige Wissensarbeit. Einfache, isolierte technische Routinen können früher automatisiert werden, wenn Input und Ergebnis bereits eindeutig sind.
