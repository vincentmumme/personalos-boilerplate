# Modul: Hermes

Hermes kann als dauerhaft erreichbarer Agent oder Laufzeitumgebung mit demselben PersonalOS arbeiten.

## So nutze ich es

Hermes bekommt keine eigene Lebenswahrheit. Er liest den synchronisierten PersonalOS-Ordner und nutzt dieselben Regeln, Owner und Skills wie interaktive Agenten.

## So kannst du es ausprobieren

Beginne lokal und nur lesend. Lege erst später einen dauerhaften Host oder Zeitpläne an und aktiviere jede externe Wirkung bewusst.

## Grenzen

Kein bestimmter Rechner, Server, Dienst, Token oder Scheduler ist vorgegeben oder aktiviert.
