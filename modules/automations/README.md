# Modul: Automationen

Automationen führen wiederkehrende Abläufe aus, nachdem Datenbasis, Regeln und manueller Prozess stabil sind.

## So nutze ich es

Ich automatisiere spät. Erst wird der Ablauf manuell verstanden, dann werden Input, Output, Owner, Fehlerfälle und Prüfung definiert.

## So kannst du es ausprobieren

Automatisiere zunächst einen rein lesenden Bericht. Aktiviere Schreibvorgänge erst mit Vorschau, Protokoll und klarer Rückfallmöglichkeit.

## Grenzen

Keine Automation, kein Cronjob und keine externe Aktion ist standardmäßig aktiv.
