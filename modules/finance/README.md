# Modul: Finanzen

Optionaler Bereich für Konten, Belege, Rechnungen, Verpflichtungen, Budgets und Berichte.

## So nutze ich es

Ich halte finanzielle Wahrheit strukturiert, unterscheide Beleg, Buchung und Bericht und behandle sensible Originaldokumente getrennt von allgemeiner Systemlogik.

## So kannst du es ausprobieren

Aktiviere nur die Record-Typen, die du brauchst. Das Modul ersetzt keine Buchhaltung, Steuerberatung oder sichere Belegablage.
