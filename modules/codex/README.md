# Modul: Codex

Codex ist ein möglicher Coding Agent, der direkt mit dem PersonalOS-Ordner arbeitet.

## So nutze ich es

Codex ist meine bevorzugte Arbeitsoberfläche für Planung, Änderungen und Prüfungen. Es liest dieselben Bootstrap-Dateien und dieselbe Systemwahrheit wie jeder andere Agent.

## So kannst du es ausprobieren

Öffne den PersonalOS-Ordner als Workspace und bitte Codex zuerst nur um eine Systemkarte. Erteile Schreibaufträge erst, nachdem Owner, Regeln und Prüfweg verstanden wurden.

## Grenzen

Codex ist austauschbar. Keine lokale Codex-Konfiguration und kein privater Pfad wird vorausgesetzt.
