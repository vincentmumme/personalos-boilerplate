# Modul: Externe Signale

Externe Signale sind Nachrichten, Calls, E-Mails, Feeds oder andere Quellen außerhalb des PersonalOS. Der Kern kann einen bereits lokal vorliegenden Beleg mit `analyse-call` verarbeiten. Dieses Modul erklärt die zusätzliche Grenze zu angebundenen oder regelmäßig eingelesenen Quellen.

## So nutze ich es

Ein Signal wird zuerst als Evidence erfasst und bewertet. Erst bestätigte, dauerhafte Aussagen werden in Menschen, Firmen, Projekte, Wissen oder andere Owner übertragen. Ein Connector liefert nur Input und darf keine zweite Wahrheit erzeugen.

## So kannst du es ausprobieren

Analysiere zuerst einen einzelnen fiktiven, lokal gespeicherten Call mit `analyse-call`. Binde eine echte Quelle erst an, wenn Zweck, Zugriff, Datenschutz und Fehlerverhalten geklärt sind.

## Grenzen

Keine Verbindung zu Gmail, WhatsApp, Discord oder anderen Diensten wird automatisch aktiviert.
