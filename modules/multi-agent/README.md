# Modul: Zusammenarbeit mehrerer Agenten

Mehrere Agenten können parallel oder nacheinander arbeiten, wenn das PersonalOS ihre gemeinsame Quelle bleibt.

## So nutze ich es

Agenten haben unterschiedliche Rollen und Werkzeuge, aber keine unterschiedlichen Wahrheiten. Aufgaben werden geplant, Zuständigkeiten getrennt und Ergebnisse in den kanonischen Owner zurückgeführt.

## So kannst du es ausprobieren

Nutze zwei Agenten für getrennte, lesende Analysen. Vergleiche ihre Quellen und führe erst danach eine kontrollierte Änderung durch.

## Grenzen

Parallele Agenten ersetzen keine Ownership-Regeln, Planung oder Konfliktprüfung.
